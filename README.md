# VoidDrag

A quiet WebGL2 art toy: part a night sky of cloud with your mouse or finger.

**Play:** open the GitHub Pages link for this repository.

- Left-drag: part the cloud / paint darkness
- Right-drag: light
- Touch: drag to paint, double-tap to switch brush
- `M` mood · `T` tune · `S` sound · `C` clear · `K` sky · `R` ride

One self-contained HTML file. No build step, no network requests.
